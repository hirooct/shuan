# 週案・学級通信アプリ（v3.2.0）

GoogleスプレッドシートとGoogle Apps Scriptで動く、週案作成・学級通信作成・連絡用スライド生成アプリです。

## v3で追加した日常入力支援

- 初回設定ウィザードと設定診断
- 別曜日の基本時間割を指定日の時間割として反映
- 「月曜2〜5時間目を1〜4時間目へ」のような時間移動
- よく使う時間割変更パターンの登録
- 前週からの週案作成（宿題・備考を除く選択可）
- 30秒ごとのユーザー別下書き保存と復元
- 保存前の入力漏れ警告
- 宿題・持ち物などの定型文登録
- 学級通信へ反映する項目の選択
- 行事・休日の複数行一括登録
- 手動・初期化前・復元前バックアップと復元
- スマートフォンでの簡易修正に対応した操作表示

アップデート通知と年度更新機能は、今回のv3には含めていません。

## v3.1 高速化

- 週案保存をセル単位から週全体の一括書き込みへ変更
- 週案起動時の複数通信を1回へ統合
- 週移動時の取得範囲を年間全体から対象週の7列へ縮小
- 基本時間割・教科・下校時刻・日付列を10分間キャッシュ
- 保存成功後の不要な再読み込みを廃止
- 下書きは15秒ごとに端末保存、3分ごとにGASへ同期
- 学級通信の2週分を1回の通信・1回のシート読込で取得
- 学級通信データの読込・保存を20セル一括処理へ変更
- バックアップ一覧は必要時だけ読み込む方式へ変更

## v3.2 学級通信の保存・写真・履歴

- 画面上の全項目（タイトル、学校・学級、上下段見出し、給食当番表示、テーマ色、写真位置など）を保存
- 空欄にした項目も空欄のまま復元
- 写真をブラウザで縮小してから、スプレッドシートと同じ場所の専用Driveフォルダへ保存
- 学級通信を保存するたびに「学級通信アーカイブ」へ履歴を自動追加
- 学級通信画面の「過去の保存を見る」から最大50件を表示・復元
- 写真の読込は文字データと分離し、画面表示を妨げない遅延読込

## 推奨する配付方法

一般の利用者にはGitHubリポジトリを直接渡さず、完成済みのスプレッドシートを「テンプレート」としてコピーしてもらう方法を推奨します。

各先生が行う操作は次の範囲にします。

1. 配付されたスプレッドシートを自分のGoogleドライブへコピー
2. 設定ページを開く
3. アプリ名、学校名、学年・組、担任名、年度を入力
4. 「Googleカレンダーから祝日を取得」を実行
5. 長期休暇、通常の時間割、教科、下校時刻、色を変える教科を設定
6. 必要な場合だけ、連絡帳用GoogleスライドのURLを登録
7. ウェブアプリを初回デプロイ

GitHubやclaspは、開発・更新を担当する管理者だけが使用してください。

## 設定ページで変更できる項目

- アプリ名
- 学校名
- 学年・組
- 担任名
- 指定年度と翌年度
- 日本の祝日
- 長期休暇
- 通常の時間割
- 教科リスト
- 下校時刻
- 色を変える教科
- 連絡帳用GoogleスライドURL

これらの変更にGASコードの編集は不要です。

## 初回利用時の権限

祝日取得、スプレッドシート読み書き、スライド生成、PDF保存などを初めて実行すると、Googleの権限確認画面が表示される場合があります。利用する先生本人のGoogleアカウントで許可してください。

高度なGoogle APIサービスを手動で有効化する必要はありません。

## 行事・休日の登録

週案ページの「休日・行事登録」ボタンから登録します。週案の行事欄は設定シートの数式で表示しているため、週案表からの直接編集はできません。

## 配付前チェック

- 「はじめに」「週案」「設定」「通信データ」シートが存在する
- 週案シートの日付・週番号・行事・休日の数式が壊れていない
- テンプレート内に前年度の児童情報や個人情報が残っていない
- 通信データ、行事、休日、備考、宿題などのサンプルデータを消している
- スライドURLが配付元の個人ファイルを指していない
- ウェブアプリの公開範囲が学校・自治体の運用方針に合っている

## .clasp.jsonについて

`.clasp.json`は配付元のGASプロジェクトを指します。一般利用者にGitHubからcloneさせる運用には向きません。テンプレートのコピー配付と、開発者向けGitHub運用を分けてください。

## 配付支援機能（v2.0.0）

設定ページに次の機能があります。

- 初期設定チェック：必須シート、年度、週番号、基本時間割、週案の日付・行事数式、スライド、デプロイ状況を確認
- 行事・休日管理：登録済みデータの一覧表示、編集、二重確認付き削除
- 配付用初期化：入力済みデータを消し、シート構造と週案の数式を保持
- スライド自動コピー：入力した原本スライドを利用者のドライブへコピーし、コピー先URLを自動設定
- バージョン表示：設定ページ上部にバージョンと更新日を表示

### 配付用初期化の安全対策

初期化には次のすべてが必要です。

1. 「元に戻せないことを理解した」チェックを入れる
2. 確認欄へ「初期化する」と正確に入力する
3. 1回目の確認ダイアログで了承する
4. 最終確認ダイアログでも了承する
5. サーバー側でも確認文字を再検証する

初期化されるのは、週案の入力欄、学級通信データ、行事・休日、年度、長期休暇、時間割、教科・下校時刻・色設定、スライドURL、学校・学級情報です。週案の日付・行事表示などの数式とシート構造は残します。

# 週案・学級通信アプリ（v3.10.1）

GoogleスプレッドシートとGoogle Apps Scriptで動く、週案作成・学級通信作成・連絡用スライド生成アプリです。

## v3で追加した日常入力支援

- 初回設定ウィザードと設定診断
- 別曜日の基本時間割を指定日の時間割として反映
- 「月曜2〜5時間目を1〜4時間目へ」のような時間移動
- よく使う時間割変更パターンの登録
- 前週からの週案作成（宿題・備考を除く選択可）
- 30秒ごとのユーザー別下書き保存と復元
- 保存前の入力漏れ警告
- 宿題・持ち物などの定型文登録
- 学級通信へ反映する項目の選択
- 行事・休日の複数行一括登録
- 手動・初期化前・復元前バックアップと復元
- スマートフォンでの簡易修正に対応した操作表示

アップデート通知と年度更新機能は、今回のv3には含めていません。

## v3.1 高速化

- 週案保存をセル単位から週全体の一括書き込みへ変更
- 週案起動時の複数通信を1回へ統合
- 週移動時の取得範囲を年間全体から対象週の7列へ縮小
- 基本時間割・教科・下校時刻・日付列を10分間キャッシュ
- 保存成功後の不要な再読み込みを廃止
- 下書きは15秒ごとに端末保存、3分ごとにGASへ同期
- 学級通信の2週分を1回の通信・1回のシート読込で取得
- 学級通信データの読込・保存を20セル一括処理へ変更
- バックアップ一覧は必要時だけ読み込む方式へ変更

## v3.2 学級通信の保存・写真・履歴

- 画面上の全項目（タイトル、学校・学級、上下段見出し、給食当番表示、テーマ色、写真位置など）を保存
- 空欄にした項目も空欄のまま復元
- 写真をブラウザで縮小してから、スプレッドシートと同じ場所の専用Driveフォルダへ保存
- 学級通信を保存するたびに「学級通信アーカイブ」へ履歴を自動追加
- 学級通信画面の「過去の保存を見る」から最大50件を表示・復元
- 写真の読込は文字データと分離し、画面表示を妨げない遅延読込

## v3.3 学級通信の写真枠・タブ編集

- 写真枠を横長16:9、横長4:3、正方形1:1、縦長3:4、自由比率から選択
- 自由比率では写真枠の幅と高さを個別に調整
- 写真枠と画像の拡大・位置設定を保存し、アーカイブからも復元
- 編集欄を「基本・ひとこま・上段・下段・連絡・設定」のタブへ整理
- 保存・アーカイブ・印刷ボタンを編集欄の下部へ固定

## v3.4 iPad用UI

- 同じウェブアプリURLのままiPad・タブレットを自動判定
- 週案は曜日タブで1日ずつ縦表示し、教科・学習内容・交換授業・メモをタッチ入力
- 週案の補助操作は「操作」ボタン内にまとめ、週移動と保存を常時表示
- 学級通信は「編集／プレビュー」を切り替えて、画面幅を有効活用
- 設定ページは上部の横スクロールナビから目的の項目へ移動
- 入力欄・選択欄・ボタンをiPadで押しやすい44px以上へ拡大
- PC表示とA4印刷レイアウトは従来どおり維持

## v3.5 Googleカレンダー同期

- Googleカレンダーから週案の行事欄への安全な片方向同期
- 設定ページで同期元カレンダーと年度内の対象期間を選択
- 終日予定・時刻付き予定・時刻表示の有無を設定
- 手動の「今すぐ同期」と、毎日5時台の自動同期に対応
- カレンダー側の名称変更・日付変更・削除を次回同期時に反映
- 複数日にまたがる終日予定は各日へ展開
- 手入力した行事は上書き・削除せず、カレンダー同期行事と画面上で区別
- 高度なCalendar APIを使わず、GAS標準のCalendarAppだけで動作

## v3.6 Google同期予定の学級通信掲載選択

- Googleカレンダーから同期した予定は、これまでどおりすべて週案へ表示
- 設定ページの行事一覧で、同期予定ごとに「学級通信へ載せる」を選択
- 「載せる」を外した予定は学級通信だけから除外し、週案からは削除しない
- 掲載設定はカレンダーの通常同期後も保持
- v3.5までに同期済みの予定は、従来の表示を維持するため初期状態を「載せる」として扱う

## v3.7 学級通信アーカイブの更新・削除

- 学級通信を保存するとき、同じ号数の過去の保存があれば最新の1件を更新
- 異なる号数、または号数が空欄の場合は新しい保存として追加
- 「過去の保存を見る」の各項目から、確認後に不要な保存を削除
- 削除しても現在編集中の学級通信データと写真ファイルは保持
- 既存の同号重複データは自動削除せず、必要なものを一覧から選んで削除可能

## v3.8 週案の1週間・2週間表示

- 週案ページで「1週間」「2週間」を切り替え
- 2週間表示は開始週と翌週をPC画面で横に並べて表示
- 2週間の両方を編集し、保存ボタン1回でまとめて保存
- 前後の週への移動は1週間単位
- iPadでは選択した同じ曜日を2週分上下に表示
- 2週間表示から印刷すると、1週間ずつA4縦2枚に自動分割
- 表示方法は端末に保存し、次回も同じ表示方法で開始

## v3.9 学級通信の印刷余白設定

- 学級通信の上下左右へ必ず同じ幅の余白を適用
- 「連絡・設定」タブから5〜25mmの範囲で余白を設定
- 画面プレビューとA4印刷へ同じ余白を反映
- 余白設定を現在の学級通信と過去の保存へ保持

## v3.10 学級通信の写真調整・A4範囲確認

- 写真枠を横長・正方形・縦長・自由比率から選び、幅と高さをより広い範囲で調整
- 自由比率の写真枠は、現在の縦横比を固定したまま幅を変更可能
- 縦横比の固定状態を現在の学級通信と過去の保存へ保持
- プレビュー上に、設定した余白を反映した実際の印刷範囲を表示
- 内容がA4からはみ出すと、超過量の目安をリアルタイムで警告
- はみ出した状態で印刷するときは確認ダイアログを表示
- PC・iPadのどちらでも、実際のA4サイズを基準に収まりを判定

### v3.10.1 写真保存の権限修正

## 推奨する配付方法

一般の利用者にはGitHubリポジトリを直接渡さず、完成済みのスプレッドシートを「テンプレート」としてコピーしてもらう方法を推奨します。

各先生が行う操作は次の範囲にします。

1. 配付されたスプレッドシートを自分のGoogleドライブへコピー
2. 設定ページを開く
3. アプリ名、学校名、学年・組、担任名、年度を入力
4. 「Googleカレンダーから祝日を取得」を実行
5. 長期休暇、通常の時間割、教科、下校時刻、色を変える教科を設定
6. 必要な場合だけ、連絡帳用GoogleスライドのURLを登録
7. ウェブアプリを初回デプロイ

GitHubやclaspは、開発・更新を担当する管理者だけが使用してください。

## 設定ページで変更できる項目

- アプリ名
- 学校名
- 学年・組
- 担任名
- 指定年度と翌年度
- 日本の祝日
- 長期休暇
- 通常の時間割
- 教科リスト
- 下校時刻
- 色を変える教科
- 連絡帳用GoogleスライドURL

これらの変更にGASコードの編集は不要です。

## 初回利用時の権限

初回デプロイ時、または写真保存など新しい権限が追加された更新後は、GASエディタ上部の関数一覧から `authorizeShuanApp` を選び、1回だけ「実行」してください。Googleの権限確認画面が表示されたら、利用する先生本人のGoogleアカウントで許可します。その後、ウェブアプリを新しいバージョンで再デプロイしてください。

この承認には、スプレッドシート、Googleドライブ、Googleカレンダー、Googleスライド、時間主導トリガーの権限が含まれます。写真はスプレッドシートと同じフォルダ内の専用フォルダへ保存されます。

高度なGoogle APIサービスを手動で有効化する必要はありません。

## 行事・休日の登録

週案ページの「休日・行事登録」ボタンから登録します。週案の行事欄は設定シートの数式で表示しているため、週案表からの直接編集はできません。

## 配付前チェック

- 「はじめに」「週案」「設定」「通信データ」シートが存在する
- 週案シートの日付・週番号・行事・休日の数式が壊れていない
- テンプレート内に前年度の児童情報や個人情報が残っていない
- 通信データ、行事、休日、備考、宿題などのサンプルデータを消している
- スライドURLが配付元の個人ファイルを指していない
- ウェブアプリの公開範囲が学校・自治体の運用方針に合っている

## .clasp.jsonについて

`.clasp.json`は配付元のGASプロジェクトを指します。一般利用者にGitHubからcloneさせる運用には向きません。テンプレートのコピー配付と、開発者向けGitHub運用を分けてください。

## 配付支援機能（v2.0.0）

設定ページに次の機能があります。

- 初期設定チェック：必須シート、年度、週番号、基本時間割、週案の日付・行事数式、スライド、デプロイ状況を確認
- 行事・休日管理：登録済みデータの一覧表示、編集、二重確認付き削除
- 配付用初期化：入力済みデータを消し、シート構造と週案の数式を保持
- スライド自動コピー：入力した原本スライドを利用者のドライブへコピーし、コピー先URLを自動設定
- バージョン表示：設定ページ上部にバージョンと更新日を表示

### 配付用初期化の安全対策

初期化には次のすべてが必要です。

1. 「元に戻せないことを理解した」チェックを入れる
2. 確認欄へ「初期化する」と正確に入力する
3. 1回目の確認ダイアログで了承する
4. 最終確認ダイアログでも了承する
5. サーバー側でも確認文字を再検証する

初期化されるのは、週案の入力欄、学級通信データ、行事・休日、年度、長期休暇、時間割、教科・下校時刻・色設定、スライドURL、学校・学級情報です。週案の日付・行事表示などの数式とシート構造は残します。
